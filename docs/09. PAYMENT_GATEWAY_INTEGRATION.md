# 09. PAYMENT GATEWAY INTEGRATION — DEVI HOSTELS

## 1. Gateway Specifications

DEVI Hostels supports dual primary payment gateway options for Indian domestic transactions:
- **Primary:** Razorpay API v1
- **Secondary / Failover:** Cashfree PG v2

Both integrations support **Instant UPI (Google Pay, PhonePe, Paytm, CRED)**, Domestic RuPay/Visa/Mastercard Credit & Debit Cards, and Net Banking across 50+ Indian banks.

---

## 2. Server-Side Payment Architecture

Frontend redirects are treated strictly as UI indicators; **no financial transaction is marked paid based on client redirect alone.**

```
[Resident Browser]                    [Next.js Server]                     [Razorpay / Bank]
       |                                      |                                    |
       |--- 1. Click "Pay ₹7,000" ---------->|                                    |
       |                                      |--- 2. Create Order (server-to-server) ->|
       |                                      |<-- 3. Return order_id & signature --|
       |<-- 4. Open Razorpay Checkout Sheet --|                                    |
       |                                                                           |
       |--- 5. Resident Completes Payment (UPI / Card) --------------------------->|
       |                                                                           |
       |                                      |<-- 6. Webhook: payment.captured ---|
       |                                      |    (HMAC-SHA256 Signature Verify)  |
       |                                      |--- 7. Idempotent DB Commit:        |
       |                                      |       - Record `payments` row      |
       |                                      |       - Update `invoices` status   |
       |                                      |       - Generate PDF Receipt       |
       |                                      |       - Trigger WhatsApp Receipt   |
       |<-- 8. UI Polling / Realtime Refresh -|                                    |
```

---

## 3. Webhook Idempotency & Security Safeguards
- Webhook endpoints (`/api/webhooks/razorpay`) compute `crypto.createHmac('sha256', secret).update(body).digest('hex')` and verify against `x-razorpay-signature`.
- The `gateway_payment_id` is indexed with a `UNIQUE` constraint in `payments`. If duplicate webhooks fire, the database rejects the second write gracefully with HTTP 200 to acknowledge delivery.
